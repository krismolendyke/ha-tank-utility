# Tank Utility (Home Assistant Custom Component)

Temporary HACS custom component for testing [home-assistant/core#186828](https://github.com/home-assistant/core/pull/186828).

## Installation via HACS

1. Open **HACS** in Home Assistant.
2. Click the **⋮** menu (top right) → **Custom repositories**.
3. Repository: `https://github.com/krismolendyke/ha-tank-utility`
4. Type: **Integration**
5. Click **Add**, download **Tank Utility**, and restart Home Assistant.
